## 3. 問答題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
**答：** 因為 `"4"` 在 Python 中是被包在引號內的字串（`str`），字串無法直接參與數學除法運算（例如進行 `1220 / "4"` 會引發 `TypeError` 錯誤）。必須先透過 `int()` 把它轉換成整數型別，電腦才能正確進行數值除法並計算出每人應付的金額。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**答：** 
- **計算結果說明：** 
  若先扣除折價券再算服務費，剩餘餐費為 $1,200 - 100 = 1,100$ 元；接著計算 10% 服務費為 $1,100 \times 0.10 = 110$ 元；最後應付總額為 $1,100 + 110 = 1,210$ 元。
- **與規定不同之原因：** 
  餐廳的服務費通常是以未折扣前的原始餐費作為基準來收取。若先扣折價券才算服務費，會導致服務費的基底變小（從 1,200 變為 1,100），使總金額少算（變為 1,210 元而不是正確的 1,220 元），這不符合多數餐廳「服務費以原始餐費計收」的商業常規與本題規則。
